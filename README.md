# Hospital-Management-Power-BI-Project
Hospital Management Analytics Dashboard Using Power BI
Hospital Management Analytics Dashboard

Project Overview

This project focuses on analyzing hospital operations and performance using Microsoft Power BI. The dashboard provides insights into patient records, hospital performance, admissions, doctors, treatments, payments and regional hospital distribution.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Project Modules

- Hospital Overview
- Hospital Details
- Patient and Doctor Analysis
- Regional Analysis

Key Features

- Interactive dashboard and slicers
- Hospital performance analysis
- Patient and admission analysis
- Doctor and department analysis
- Bed availability and occupancy analysis
- Revenue and payment analysis
- Regional performance comparison

Skills Demonstrated

- Data modelling
- Data cleaning and transformation
- DAX calculations
- Interactive reporting
- Data visualization
- Business insights
